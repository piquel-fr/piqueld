# Security policy

## Reporting a vulnerability

Email [security@piqueld.dev](mailto:security@piqueld.dev). Don't open a public
issue or pull request for a vulnerability, and don't disclose it publicly until
a fix is released.

Include what you found, how to reproduce it, the piqueld version or commit, and
what an attacker could do with it.

## Supported versions

piqueld has no stable release yet. Only the latest `main` receives security
fixes.
